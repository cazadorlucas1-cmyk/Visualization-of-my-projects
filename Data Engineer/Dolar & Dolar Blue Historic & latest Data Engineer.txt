The project consists of extracting and manipulating data from an API for collecting the current Argentine dollar exchange rate, both historical (from 2011 to the present) and incremental, using a created table for new data from 2026 onwards. The updated data is stored with raw data and subsequently manipulated and queried in a Python table to collect the data requested by the company and store it in a MinIO database.

In the next part of the work, I remove null and duplicate values, redefine some data types, rename columns for better readability, and format date columns to avoid conflicts with others. I use the `min` and `max` functions and the `avg` function of the Evolution dataframe.

Finally, I extract the collected data and save it in Delta Lake format for later interpretation, manipulation, and visualization by data analysts.
